# 💊 Medi-Store — Online Medical Store

Medi-Store is a Django-based web application developed as an online medical store platform. The project demonstrates the development of a web-based system for managing and displaying medicines through a structured Django application.

## 📌 Project Overview

The application is designed to provide an organized interface for an online medical store, where medicines can be managed and presented to users through a web application.

The project was developed to gain practical experience with:

- Django web development
- Python backend development
- Database-driven applications
- Django models and migrations
- HTML templates
- Static and media files
- CRUD-based application design

## ✨ Features

- 🏥 Online medical store interface
- 💊 Medicine management
- 🖼️ Medicine image support
- 📋 Medicine information display
- 🗄️ Database integration using Django
- 🌐 Django-based web application
- 📁 Organized application structure

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| Python | Backend programming |

| SQLite | Database |
